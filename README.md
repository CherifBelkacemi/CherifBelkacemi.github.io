# Cherif Belkacemi - academic website

A static, responsive academic portfolio. The published files live in `dist/`.

## GitHub Pages

This repository publishes `dist/` through the included GitHub Actions workflow when changes are pushed to `main`. The site URL is `https://Kyr6.github.io/`. GitHub Pages must use **GitHub Actions** as the publishing source in **Settings  Pages  Build and deployment**.

No build, dependencies, tracking scripts, or external assets are required. Open `dist/index.html` locally to preview.

Content is based on Cherif Belkacemi's 2026 CV and doctoral research proposal. The quote supplied for the page is attributed to B. V. Gnedenko and A. N. Kolmogorov.
